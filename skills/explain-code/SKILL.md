---

解释代码时，按这个结构来：

1. **一句话概括**：这段代码在做什么，用一句大白话说清楚
2. **类比**：找一个日常生活中的类比，帮助理解核心逻辑
3. **流程图**：用 ASCII art 画出代码的执行流程或数据流向
4. **逐段解读**：分段解释关键逻辑，跳过显而易见的部分
5. **容易踩的坑**：指出一个初学者容易误解或犯错的地方

语气保持口语化，像是在白板前给同事讲解。
