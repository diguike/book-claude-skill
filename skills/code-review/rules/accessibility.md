# 无障碍 (a11y) 审查规则

审查包含 `aria-`、`role=`、`tabIndex` 或交互元素的代码时使用。

## 1. 语义化 HTML

- 用 `<button>` 而不是 `<div onClick>`，因为 button 自带键盘事件和 ARIA 角色
- 用 `<nav>`、`<main>`、`<aside>` 等语义标签而不是 `<div>`
- 用 `<a>` 做导航链接，用 `<button>` 做操作按钮，不要混用

## 2. 键盘导航

- 所有可交互元素必须能通过 Tab 键聚焦
- 自定义组件要处理 Enter 和 Space 键（模拟点击）
- 模态框打开时焦点应锁定在模态框内（focus trap）
- 模态框关闭后焦点应回到触发按钮

## 3. ARIA 属性

- 图片要有 `alt` 文本，装饰性图片用 `alt=""`
- 自定义控件要有 `role` 和 `aria-label`
- 加载状态用 `aria-busy="true"`
- 错误提示要关联到输入框：`aria-describedby`

## 4. 颜色和对比度

- 不要只用颜色传达信息（色盲用户无法区分）
- 错误状态除了红色还应有图标或文字提示
- 对比度满足 WCAG AA（正文 4.5:1，大字 3:1）

## 5. 表单

- 每个输入框必须有关联的 `<label>`（用 `htmlFor` 或包裹）
- 必填字段标记 `required` 属性
- 表单验证错误要在错误发生的位置显示，不要只弹 toast
