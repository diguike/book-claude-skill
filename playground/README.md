# Playground

在这个目录里动手练习。

你可以在这里创建自己的 Skill，运行 eval，尝试各种配置。这个目录下的内容不会被 git 跟踪（已加入 .gitignore）。

## 快速开始

```bash
# 复制模板
cp -r ../templates/skill-starter/ my-first-skill/

# 编辑 SKILL.md
code my-first-skill/SKILL.md

# 复制到 Claude Code 的 skills 目录
cp -r my-first-skill/ ~/.claude/skills/my-first-skill/

# 打开 Claude Code，试试触发你的 Skill
```
